本文用中文记录**当前真实进度**，方便组内对齐。对外说明与运行方式见仓库根目录英文 [`README.md`](../README.md)。

## 1. 我们在做什么

面向 **EU Agri-Hackathon 2026**，主赛道是**挑战三：数据流动，赋能协作**。

产品暂名 **Origin**：农民一侧的「编译器 + 同意钱包 + 收据本」。田间事实采集一次，按目的、时限、最小字段打包给合作社 / 磨坊 / 零售 / 认证方；可撤回；每次分享留收据。

- 不是再做一个农场管理软件（FMIS）
- 不是再做一个数据交易市场
- 挑战一（少填表）和挑战二（田间数据）只当输入和副产品

口号：You originated it. You decide who uses it.

参考农场：法国演示场「Ferme des Bords」，86 ha，6 块地，3 号地贴河边（GAEC 4 缓冲带 5 m）。演示合作方：Loire Cereals Co-op。

## 2. 已经定下来的架构

| 决策 | 内容 |
|---|---|
| 语言 | 农民端 **TypeScript / Next.js PWA**；API **Python 3.12+ / FastAPI**。不混成一套语言。 |
| 部署形态 | 两个 Cloud Run：`origin-web`、`origin-api`，闲置缩到 0，区域 `europe-west1` |
| 模型 | 只用 **Gemini Flash-Lite**。浏览器不持有密钥。规则与 GAEC **禁止**让模型裁决。 |
| 交互 | 农民只有四屏：Today → Speak/Snap → Consent → Who has it。合作方桌 `/desk` 农民进不去。 |
| 同意状态 | `draft` → `purpose-bound` 或 `refused`；`purpose-bound` → `expired` 或 `revoked`。拒绝是终态，不删草稿。 |
| 合规 | 导出 `GET /v1/me/export`（GDPR 第 20 条）；删除 `DELETE /v1/me`（第 17 条） |
| 图 | OPM（ISO/PAS 19450）+ Graphviz DOT，标签全英文 |

图文件在 `opm/`，渲染结果在 `opm/rendered/`。前后端细规在 `docs/frontend-backend.md`。

## 3. 时间线（到今天）

### 选题与设计

- 对照官方申请人手册与三个挑战，锁定挑战三。
- 用美国农民公开痛点（Deere/FieldView 锁数据、电梯/碳项目问卷、Ag Data Transparent）映射到欧盟合作社问卷与 OEM 云。
- 从 farmOS、LiteFarm、EDC、sonu-ai 等仓库抽出「只借模型/交互、不借整套 FMIS」的原则。
- 农民端写成交互宪法：大按钮、强对比、语音/拍照优于表单。

### 架构与专家审核

专家指出总图缺伙伴请求流、过期路径、若干悬空节点后，已补上：

1. 合作社请求 → Today 一张卡 → 同意（挑战三主场景）
2. Import Adapter 标为 phase 2
3. Expiring（到期作废令牌）
4. 撤回/过期后面文件变灰
5. Firestore / GCS / Auth 接到 API
6. 交货通行证由 Delivering 产出
7. Gemini 框写明 context cache、日配额、账单上限；PWA 标明离线队列
8. sd1 与 states 对齐：含 expired，并交代 Partner Request 来源

随后补了三条原「建议未动」：

- **Refuse**：终态 `refused`，Desk 410，收据留「你说过不」
- **i18n**：首次选国家写入 `locale`，白话同意卡按农民语言生成
- **GDPR**：Who has it 上导出 / 删除，不新开第五屏

### 实现（本机已跑通）

已搭垂直切片，不是空目录：

| 模块 | 路径 | 状态 |
|---|---|---|
| API | `apps/api/origin/` | FastAPI：采集、YAML 编译、同意、交付、几何、Gemini 路由、演示种子 |
| 规则包 | `apps/api/rules/coop_ppp_statement.yaml` | 合作社植保声明；排除产量与收入 |
| 农民端 | `apps/web/app/` | Today / Capture / Consent / Receipts |
| 合作方桌 | `apps/web/app/desk/` | 只读份额包；变灰；可再发请求 |
| 本地库 | `apps/api/data/`（不入库） | JSON，免 Firebase 也能演示 |
| 测试 | `apps/api/tests/` | 3 通过，含周日闭环 |

本机验证（2026-08-16）：

- `pytest tests -q`：3 passed
- `npx tsc --noEmit`：通过
- `GET /v1/today` 返回演示农场、6 地块、合作社未结请求
- 农民端 http://localhost:3000 ，API http://127.0.0.1:8000/docs

未配置 `GEMINI_API_KEY` 时走启发式抽取 + 英/法模板，闭环仍可走完。有 key 才调用 Flash-Lite。
